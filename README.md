# Personal website

My personal website. Plain HTML and CSS with a little vanilla JavaScript, hosted on GitHub Pages.

All the content lives in the `data/` folder as plain JavaScript objects. Each section of the site (experience, research, skills, and so on) reads from one file there, so updating the site usually means editing one list and pushing.

- `index.html`: the main page
- `research.html`: publications in more detail
- `data/`: all content
- `js/render.js`: builds the pages from the data
- `css/style.css`: styles
- `assets/`: images, favicon, and the downloadable resume
