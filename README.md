# Personal website

My personal website. Plain HTML and CSS with a little vanilla JavaScript, hosted on GitHub Pages.

Live site: https://sushantjha78.github.io/portfolio/

All the content lives in the `data/` folder as plain JavaScript objects. Each section of the site (experience, research, skills, and so on) reads from one file there, so updating the site usually mean[...]

- `index.html`: the main page
- `research.html`: publications in more detail
- `data/`: all content
- `js/render.js`: builds the pages from the data
- `css/style.css`: styles
- `assets/`: images, favicon, and the downloadable resume
